# QuickAdd

The floating burgundy Quick Add button that sits above the bottom navigation.

## Use it

- Show only to people allowed to create on that screen (Ayush & Mahi for tasks and events). Family editors and viewers get no Quick Add.
- Sits 18px from the right, above the glass nav; content scrolls clear of it.
- `extended` adds the label on wide or first-use screens.

## Props

`label, extended, onClick`

All colours, spacing and radii come from the tokens; the component never hard-codes a value.
