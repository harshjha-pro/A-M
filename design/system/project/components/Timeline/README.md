# Timeline

Vertical step timeline for outfits and decor items.

## Use it

- State is shown three ways: filled tick / ring / dashed number, a word (Done, Now, Next), and colour — readable in grayscale.

## Props

`steps: {title, state: 'done'|'current'|'next', meta, extra}[]`

All colours, spacing and radii come from the tokens; the component never hard-codes a value.
