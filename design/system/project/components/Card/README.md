# Card

The solid white content card with optional title, icon and "See all" link.

## Use it

- Lists, forms, money and reading text always sit on solid cards — never glass.
- Tones: `blush` (summary headers), `cream` (quiet info), `warning`/`danger` (Everyone’s overdue).

## Props

`title, icon, action, to, tone, pad, children`

All colours, spacing and radii come from the tokens; the component never hard-codes a value.
