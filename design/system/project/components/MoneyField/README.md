# MoneyField

The rupee amount input; accepts 50000, 1,25,000 or 1.25 lakh.

## Use it

- Keeps exact paise precision; validation message: "Enter an amount, like 50000 or 1.25 lakh."
- Money changes need internet — disable Save offline and say so.

## Props

`label, value, help, error`

All colours, spacing and radii come from the tokens; the component never hard-codes a value.
