# GlassPanel

Frosted translucent surface for small overlays on photos and floating controls.

## Use it

- Only for: countdown tiles, nav, selected chips, photo overlays, small stat tiles, sheets and dialogs.
- 18px blur, `glass-white` or `glass-blush`, `glass-border`, `shadow-glass`; text stays `text` or `primary`.

## Props

`tone: 'white'|'blush', style, children`

All colours, spacing and radii come from the tokens; the component never hard-codes a value.
