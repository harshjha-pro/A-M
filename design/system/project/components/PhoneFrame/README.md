# PhoneFrame

390 × 844 phone frame with status bar, safe areas, glass nav, Quick Add and overlay slots.

## Use it

- Used by every mobile screen design. `offline` shows the no-internet strip.

## Props

`children, nav, fab, toast, overlay, label, darkStatus, offline, height, theme`

All colours, spacing and radii come from the tokens; the component never hard-codes a value.
