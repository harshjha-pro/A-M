# Chip

Filter and choice chip; the selected chip is frosted blush glass with a tick.

## Use it

- Filters sit in a horizontally scrolling `ChipRow`; choice sets (assignees, invite to) wrap.
- Selected = tick + `glass-blush` + burgundy border: shape and icon, not just colour.

## Props

`children, selected, icon, count, tone, onClick`

All colours, spacing and radii come from the tokens; the component never hard-codes a value.
