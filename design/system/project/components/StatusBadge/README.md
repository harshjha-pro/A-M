# StatusBadge

Icon + word status pill for tasks, Coming?, payments, roles, diets and attachment types.

## Use it

- Every status has a word AND an icon; colour is a third cue only.
- Use the product's words: To do, Doing, Waiting, Done, Cancelled · Coming, Waiting, Not coming, Not asked yet · Paid, Due, Overdue · Waiting to send.

## Props

`status, children (override the label), size: 'sm'|'md'`

All colours, spacing and radii come from the tokens; the component never hard-codes a value.
