# Checkbox

Square checklist box and the large round task-completion control.

## Use it

- `lg` round = complete a task (leads to the Undo bar). Square = checklist items.
- Checked = burgundy fill + tick; text strike only for checklist items.

## Props

`checked, label, sub, strike, size: 'md'|'lg', onChange`

All colours, spacing and radii come from the tokens; the component never hard-codes a value.
