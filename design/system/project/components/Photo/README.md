# Photo

Rounded image container with optional bottom scrim and overlay content.

## Use it

- Use `scrim` (or `scrim-top`) whenever white text sits on a photo.
- `label` marks a placeholder slot to replace with the couple’s own photo.

## Props

`name (Photography asset), src, ratio, radius, overlay: 'scrim'|'scrim-top', label, children`

All colours, spacing and radii come from the tokens; the component never hard-codes a value.
